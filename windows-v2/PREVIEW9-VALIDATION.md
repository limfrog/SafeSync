## 실계정 읽기 전용 진단

실행 중 앱 결과는 Recent Backup 동일 17,868개 / 반복 충돌 57개 / 일반 오류 0개였다. 카탈로그의 실제 중복 경로는 12개이며 관련 상위 폴더까지 충돌로 표시돼 있었다. 표시된 최상위 폴더 자체는 실제 Drive에서 하나였다.

실제 충돌 파일 3개(4,096 / 4,096 / 9,520바이트)를 표본으로 검사했다. 각 파일에 같은 이름의 원격 사본 2개가 있었으며 모든 사본의 내용 체크섬이 해당 원본과 일치했다. 나머지 9개가 모두 같다는 의미는 아니다. 새 엔진이 다음 백업에서 각 사본을 직접 확인한다. 일반 파일 3개도 별도로 내용 일치를 확인했다.

HTTP 진단 처리기는 Google Drive GET과 OAuth 토큰 갱신 POST만 허용하고 파일 변경 요청을 차단했다. 클라우드 쓰기 0회, 계정 설정 파일 SHA-256 불변이다. 실제 백업 폴더에서 복사·삭제·복구·보존 이름 변경을 실행하지 않았다.
