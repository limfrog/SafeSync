# Windows 1.0.0-preview.13 업데이트 기능 검증

2026-10-21 · Horizon Entertainment · apps@horizonent.co.kr

## 변경

- GitHub 고정 배포 정보 기반 자동 확인·다운로드와 환경설정/도움말/알림 영역의 수동 확인.
- 자동 확인·자동 다운로드 설정을 개별 보존. 새 버전 반복 팝업·강제 설치·숨김 상태의 알림음을 사용하지 않음.
- 허용 URL·파일명·버전·용량·SHA-256 검증, 전송 중 임시 파일 분리 및 오류/취소 정리, 설치 직전 재검증.
- 설치할 때 신규 작업 시작을 막고 실행 중인 현재 파일을 마침. 작업 일시정지/종료 설정을 바꾸지 않고 스냅샷의 미완료 경로 유지.
- 업데이트 목록 자동 생성 도구와 GitHub 작업 추가. 신규 설치 파일과 체크섬을 게시한 경우에만 새 버전 알림.

## 검사

- 전체 격리 C# 백업·마이그레이션·안전성 검사 **997개 통과**. 이 중 업데이트 전용 **39개**는 실제 계정/외부 서버 없이 HTTP와 파일 오류를 모의 재현한다.
- 프리뷰 숫자 정렬, 정식판의 프리뷰 제외, 잘못된 버전·주소·리다이렉트·과대 응답 거부.
- 정상 다운로드·캐시 재사용·변조 캐시 재검증·손상 파일 거부·전송 중단·취소 후 임시 파일 정리.
- 설치 대기 시 현재 파일 완료, 다음 파일 미처리/대기 기록 유지, 신규 실행 차단, 대기 해제 후 재개.
- 라이트·다크 UI **563개 검사 통과**: 업데이트 설정 초기값, 수동 확인 버튼, 검증 전 설치 비활성화, 모델리스 창, 최소 크기 버튼 배치 및 종료 포함.
- Windows 앱 빌드 경고 0개·오류 0개. 실행 시 PowerShell 미로드 및 포함된 .NET 런타임 사용 확인.

## 범위와 한계

실제 사용자의 실행 중 앱을 자동 교체하거나 기존 클라우드 파일·계정·작업 설정을 바꾸지 않았다. 실서비스 전체 백업 검사를 반복한 릴리스가 아니다. 체크섬은 저장소 자체 탈취에 대한 독립된 서명이 아니며 Windows 코드 서명은 아직 없다.

macOS 0.3.9 (18)는 자동 확인·검증 ZIP 다운로드·Finder 열기를 제공한다. GitHub macOS 실행 `39554150051`의 Universal 빌드·서명·번들 검증 통과. 앱 교체는 사용자가 종료 후 진행하며 Windows의 자동 설치 방식과 다르다. macOS 업데이트 UI의 실제 기기 조작 검증 및 전체 클라우드 검사는 별도다.

최종 설치 페이로드와 공개 다운로드 주소 검증은 배포 인계 기록에서 확인한다. 사용 방법은 [UPDATES.md](UPDATES.md).
