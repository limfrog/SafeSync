# SafeSync 1.0.0-preview.12 — 개발자·문의 정보 통일

변경일: 2026-10-21

- 개발자·운영자: **Horizon Entertainment**
- 개발자·기술 지원·개인정보 문의: **apps@horizonent.co.kr**
- 앱 정보창, 어셈블리의 회사·저작권, Windows 설치 등록의 게시자·연락처·지원 링크에 적용한다.
- 이전 PowerShell 참고 소스와 macOS 정보창·빌드 저작권에도 같은 정보를 적용한다.
- 홈페이지 개별 소개와 개인정보처리방침, GitHub 안내·개인정보처리방침에도 반영한다. SafeSync의 별도 이용약관 파일은 현재 저장소에 없었다.
- 백업·동기화 엔진의 동작은 프리뷰 11과 같다. 사용자 계정·작업·스냅샷·설치 경로를 변경하지 않는다.
- 별도 공개 지시 전까지 홈페이지 Apps 목록의 SafeSync 비노출 설정을 유지한다.

이번 수정은 표시·문의 정보와 빌드 메타데이터에 한정한다. 컴파일, 설치 패키지 및 공개 페이지 반영 결과는 최종 게시 인계 기록에 남긴다.
