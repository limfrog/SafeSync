## 운영 및 남은 범위

자세한 동작은 [PREVIEW16-VALIDATION.md](PREVIEW16-VALIDATION.md)를 참고한다. 네트워크 오류는 현재 동기화 끝에 한 번 재시도하고 지속 실패 시 지연한다. 인증·권한·공간·체크섬 오류와 실제 충돌을 자동 덮어쓰기하지 않는다. 예약 처리는 이번 앱 실행 동안만 유지하고 미실행 명령을 재시작 후 자동 복원하지 않는다. 이미 시작한 전송의 기존 안전 복구 기록은 유지한다.

실계정 Google Drive/Dropbox API, 실제 NAS 장애·Windows 10/11 일반 권한·실제 재부팅·장기 운전·전송 도중 전원 차단은 이번 검증 범위가 아니다. 아직 공개 프리뷰이며 코드 서명 전이다. macOS 0.3.12(21)는 변경하지 않는다.

사용자 앱을 실행·종료·설치하거나 실제 설정·계정·스냅샷·백업을 수정하지 않았다. GitHub와 개별 홈페이지 및 업데이트 목록에 게시하며 설치해야 수정이 적용된다. 홈페이지 `/apps/` 목록의 SafeSync 비노출을 유지한다.
