# SafeSync Windows 사용 안내

현재 버전: **1.0.0-preview.29 공개 프리뷰**. 정식 안정판이나 코드 서명 완료를 뜻하지 않습니다.

Windows 10/11 x64에서 설치 파일을 실행하거나 무설치 ZIP을 풀어 SafeSync.exe를 실행합니다. 시작하면 알림 영역에 표시되며 아이콘에서 창을 열 수 있습니다. 창을 닫아도 백업은 유지되고 알림 영역의 프로그램 종료로 완전히 종료합니다.

업데이트와 제거는 작업·계정·백업 기록을 보존합니다. 이전 작업은 파일 메뉴의 작업 목록 가져오기로 불러오며, 가져온 작업은 일시정지 상태에서 위치를 확인한 뒤 실행하세요. 설정 폴더 이름은 기존 자료와의 호환을 위해 유지합니다.

Windows VSS는 관리자 권한·로컬 NTFS·단방향 원본에 한해 선택할 수 있습니다. 기본으로 꺼져 있으며 일반 백업 때문에 관리자 실행을 요구하지 않습니다.

## 백업과 동기화

로컬 드라이브·NAS·Dropbox는 단방향 백업과 양방향 동기화를 지원합니다. Google Drive는 제한 권한(`drive.file`)으로 SafeSync 관리 폴더에 단방향 백업합니다. 양방향은 양쪽의 삭제도 반영하므로 작업을 만들 때 방향을 확인하세요.

단방향 작업의 삭제 반영은 작업 수정 화면의 **원본에서 사라진 파일은 백업 위치의 SafeSync 휴지통으로 이동**에서 선택합니다. 해제하면 원본에서 삭제된 파일도 백업에 남습니다.

**작업 종료**는 현재 파일을 안전하게 마치고 대기하며, **일시정지**는 현재 작업을 잠시 멈춥니다. 사용 중인 파일은 대기 목록에서 다시 시도합니다. 오류·충돌은 동기화 상태 탭에서 확인하고 처리 방향을 선택하세요. 실행 중 선택한 처리는 현재 동기화가 끝난 뒤 다시 확인하여 적용합니다.

## 복원과 보호

휴지통 탭에서 실행별·파일별로 조회하고 여러 파일을 복원할 수 있습니다. 대량 변경 보호는 기본 100개 이상이면서 기존 파일의 20% 이상인 변경·삭제를 실행 전에 보류합니다. 전체 검사·백업 복원 검증·보관 사본 검증도 사용할 수 있습니다.

Google Drive 보관 사본은 보관 종료나 사용자 제거 후 Google 휴지통으로 이동합니다. Google 휴지통에서는 보통 30일 더 복원할 수 있으며 그동안 저장 공간을 사용합니다. 다른 위치의 보관·삭제 정책과 복원 절차는 [보호·복원 안내](https://github.com/limfrog/SafeSync/blob/main/RECOVERY-GUIDE.md)를 확인하세요.

## 설정·업데이트·문의

환경설정에서 테마·알림음·자동 시작·클라우드 연결·업데이트를 관리합니다. **업데이트 확인**으로 새 버전을 확인하고 다운로드할 수 있습니다. 상세 작동 로그는 환경설정 맨 아래에서 문제가 있을 때만 켜고, 확인 후 끄세요. 활동기록과 작업 결과는 계속 표시됩니다.

기존 제한 권한 Google Drive 작업은 이어 사용합니다. 예전 전체 Drive 권한 계정은 재연결 후 새 관리 폴더 작업으로 이전해야 합니다. 기존 백업은 자동 삭제하지 않습니다.
