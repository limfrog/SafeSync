## 범위와 남은 제한

수정 전 실패는 [기존 재현 기록](RESTART-REPRODUCTION-20261022.md), 수정 상세와 첫 검사 결과는 [수정 검사 기록](PREVIEW15-VALIDATION.md)에 보존했다. SMB에서는 감시 공백의 안전한 전체 비교가 남지만 불필요한 재복사·잘못된 폴더 충돌은 없었다. 변경 저널 만료·접근 권한 부족도 전체 비교로 복구하며 관리자 실행·쓰기 권한·서비스 설치를 강제하지 않는다.

실제 NAS/Samba·Google Drive/Dropbox 계정, Windows 10/11 일반 사용자 권한의 저널 성능, 실제 재부팅·장기 운전·전송 중 전원 차단은 이번 검사의 범위가 아니다. 모의 클라우드 회귀를 실제 API 인증으로 간주하지 않는다. 아직 공개 프리뷰이며 코드 서명 전이다. macOS는 기존 0.3.11을 유지한다.

실행 중인 사용자 앱을 종료하거나 새 버전을 설치하지 않았고 실제 설정·계정·스냅샷·백업 파일도 변경하지 않았다. 설치파일은 상위 `dist/`에 게시하며 설치해야 이번 수정이 반영된다. 개별 홈페이지와 업데이트 목록은 갱신하되 홈페이지 `/apps/`의 SafeSync 비노출은 유지한다.
