# Preview 29 / macOS 0.3.25(34) — 배포 정리 검증

## 변경 범위

- 시작 활동기록의 클라우드 API·승계 검증본 안내 제거. 시작 버전과 실제 결과·오류 기록은 유지.
- 설치·제거 화면의 구현 언어·구버전 별도 설치 문구 제거. 기존 자료 보존 안내와 실제 프리뷰 버전 표시는 유지.
- 구버전 중복 실행 및 잘못된 설정 경로의 차단은 유지하고 안내 문장만 정리.
- Windows/macOS 사용 안내를 현재 기능 기준으로 재작성. 역사적 검증 문서는 Git 이력/소스에 보존하며 설치 패키지에서는 제외.
- Windows 패키지의 디버그 심벌 복사 제외, 이전 검증 보고서·소스·테스트 실행 파일 혼입 시 빌드 실패.
- 설치 파일 `/verify`의 임시 압축 해제 폴더를 성공·실패 모두 정리. 정리 대상은 해당 실행에서 생성한 고유 폴더로 제한하고 연결 폴더를 거부.

## 제거하지 않은 요소와 이유

- SafeSync2 설치/설정 경로, 등록 키, mutex, 제어 채널: 기존 설치·작업·계정·스냅샷과의 호환에 필요.
- 기존 설정 가져오기 및 구버전 동시 실행 차단: 사용자 자료 이전과 중복 쓰기 방지에 필요.
- 임시 전송·체크섬·교체 저널·휴지통·복원 검증·VSS: 정상 백업의 파일 보호에 필요.
- 선택형 상세 로그(기본 꺼짐), 활동기록: 장애 분석과 결과 확인 기능.
- Windows `--smoke-test` 격리 검사 진입: 실제 배포 바이너리의 UI·런타임 회귀 검증에 필요. 사용자 데이터 폴더를 쓰지 않는 전제 유지.
- macOS DEBUG 원격 저장소/데이터 폴더 주입: release에서 컴파일 제외됨. SafeSyncChecks는 별도 타깃이며 앱에는 복사하지 않음.
- PowerShell 빌드 스크립트: 개발·CI 도구이며 앱 실행에 사용하거나 설치본에 포함하지 않음.
- 이전 배포본·0.3.7 OAuth 등록 리소스: 배포 이력과 macOS 빌드에 필요하므로 일괄 삭제하지 않음.

## 검증

- 로컬 설치 엔진: 37개 통과(검증 성공/손상 실패 후 임시 폴더 정리, 관련 없는 설정 보존 포함).
- 앱 빌드: 경고/오류 없음.
- 전체 회귀·UI·macOS·최종 설치본: 진행 중. 완료 후 아래에 실제 결과 기록.
- 사용자 실행 앱·작업·계정·클라우드 데이터는 변경하지 않음. 실제 클라우드 부하/장시간 실행을 새로 수행했다는 뜻이 아님.
