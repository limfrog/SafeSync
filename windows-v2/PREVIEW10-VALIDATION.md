# SafeSync 1.0.0-preview.10 최종 검증 — 2026-10-19

## 변경 범위

- 메인 작업 도구줄의 휴지통 관리·동기화 상태 버튼을 제거하고 탭과 보기 메뉴는 유지했다.
- 환경설정 아이콘을 공통 탭 제목줄 오른쪽으로 이동했다. 탭 패널 오른쪽 48픽셀을 예약해 겹침을 방지한다. 개별 탭 안의 작업 도구줄과 분리되어 모든 탭에서 보인다.
- 작업 관리를 새 작업 옆 왼쪽에 두고 생성·관리와 실행 그룹 사이에 구분선을 배치했다.
- 빈 휴지통 안내도 버튼이 아닌 탭 이동을 설명하도록 변경했다.

UI는 Light/Dark, 800×540 및 1180×720, 세 탭 모두에서 설정 버튼 표시·활성화·제목줄 중심 정렬·비겹침을 검사했다. 실제 설정 버튼을 클릭해 설정 창을 열고 닫은 뒤 선택 탭과 메인 활성 상태를 확인했다. 작업 관리 왼쪽 정렬·중복 버튼 제거·휴지통 안내를 검사하고 화면 PNG도 검토했다. 기존 활동기록 드래그·저장과 동기화·복구 UI 회귀 검사도 유지한다.

마지막 빈 휴지통 안내문/해당 UI 검사 추가 후에는 UI를 다시 출판하고 묶음·설치 후 검사를 모두 재실행했다. 백업 엔진 소스는 변경하지 않았으며 최종 SafeSync.Core.dll은 860개 검사에서 사용된 DLL과 SHA-256이 같다: `88278DBBD0508CB544BC822010C92328A7C75CE727E5120F8B32916094A9586E`.

빌드·검증 단계에서는 실행 중 앱과 실제 작업·계정·스냅샷·클라우드/NAS 파일을 변경하지 않았다. 이후 사용자 요청에 따라 이 검증본의 소스·설치파일·검사 문서를 GitHub와 홈페이지에 공개한다. 실행 중 앱은 자동 업데이트하지 않는다.
