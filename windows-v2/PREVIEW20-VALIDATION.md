# Windows preview.20 — Google Drive 검증 및 자동 정리

연결 검증이 실제 백업 작업의 계정·폴더 초기화를 중복 실행하던 경로를 제거했다. 검증은 계정 루트 아래의 고유한 `.safesync-validation-<UUID>` 폴더에서만 수행하며, 성공·실패·취소 뒤 해당 폴더와 모든 내용을 최대 3회 자동 삭제한다. 전체 검증은 3분 안에 응답이 없으면 명확한 시간 초과 결과를 연결 창에 표시한다.

검증 범위는 계정·선택 루트 접근, 전송과 서버 체크섬, 변경 없는 파일 건너뛰기, 안전 교체, SafeSync 휴지통 이동·복구 및 검증 폴더 정리다. 기존 작업 폴더와 사용자 파일은 사용하지 않는다.

최종 GitHub Actions 실행 번호와 배포 파일 SHA-256은 빌드 완료 후 이 문서와 `PREVIEW20-PACKAGE-RESULT.md`에 기록한다.
