# Windows preview.17 · macOS 0.3.13 — 2026-10-22

Windows 환경설정의 업데이트 확인 버튼만 남기고 중복 다운로드/설치 진입 버튼을 제거했다. 기존 업데이트 화면에서 검증 다운로드와 사용자 승인 후 설치를 계속 제공하며 자동 확인/다운로드 선택도 유지한다. Windows 백업·재시도 엔진은 preview.16과 동일하다.

macOS 0.3.12의 독립 재현은 [GitHub 실행 39725281365](https://github.com/limfrog/SafeSync/actions/runs/39725281365), 소스 `9d8c3a031a3c312aa10e5026fefe80d4fbf2f42a`에서 수행했다. 당시 제품 코드는 바꾸지 않고 모의 Google Drive/Dropbox의 단방향/양방향 네 경우에 일회성 503 오류가 일반 오류로 남고 다음 실행에 복구됨을 재현했다. Store의 확인 메시지·오류 알림 및 문제 해결 필터, 실행 중 비교 차단과 지연 재시도 조건을 소스에서 별도로 확인했다. 초기 검사용 코드의 비공개 생성자 접근 오류는 공개 HTTP 오류 생성 경로로 수정한 뒤 전체 재실행했다.

macOS 수정은 네트워크 오류의 자동 분류·오류 목록 보존·확인 메시지/알림 제외·현재 동기화 끝 한 번 재시도 및 지속 실패 지연, 실행 중 파일별 처리 예약·실행 전 마지막 선택 우선·선택 취소·파일/위치 재검증을 포함한다. 대기 상태의 수동 확인/적용은 유지한다. 예약은 세션 한정이며 중단·종료·작업 자체 실패·연결 변경은 미실행 명령을 취소한다. 기존 전송 복구 저널·백업 데이터·설정·Keychain 식별자를 유지한다. 환경설정의 업데이트 진입 버튼도 하나로 통합한다.

검사는 GitHub의 macOS 및 Windows 격리 환경에서 수행하며 사용자 PC에서는 실행 테스트·설치를 하지 않는다. Mac 앱의 실제 Store 코드를 다른 진입점으로 컴파일하고 모의 원격 저장소만 주입하여 예약·마지막 선택·취소·현재 실행 이후 처리·사본 보존, 일회/지속 네트워크 오류·최종 재시도·메시지 제외·지연을 검사한다. 화면에서 실제 마우스로 버튼을 누르거나 실서비스 계정/NAS를 사용하는 검사와 구분한다. 최종 결과·다운로드 해시는 완료 후 별도 배포 검사 기록에 기재한다.
