# Windows preview.27 · macOS 0.3.23(32) 검증

2026-10-27. 런타임 소스: Windows `fcbf296`, macOS `15c67ac` (복원 게시 직전 체크섬 재확인 포함).

## 변경 내용

- 기존 성공 파일의 대량 변경·삭제를 일반 전송 전에 보류하고 정확한 변경 집합에 대해서만 다음 실행 1회 승인한다. 기본 100개/20%이며 작업별 설정을 저장·내보내기·가져오기한다.
- 휴지통 항목에 실행 묶음과 보관 체크섬을 기록하고 실행별 필터·다중 복원·선택 사본 검증을 제공한다. 같은 경로의 여러 버전 동시 복원을 거절한다.
- 마지막 성공 백업을 별도 임시 위치에서 읽는 검증과 취소를 제공한다. 정상/실패/기준 없음으로 구분하며 원본이 없어도 백업을 검사한다. 사용자 원래 위치를 덮어쓰지 않는다.
- Windows 단방향·로컬 NTFS 원본의 잠긴 파일에 선택형 VSS를 제공한다. 기본 꺼짐, 이미 관리자 권한으로 실행한 경우에 한하며 불가 시 기존 잠김 대기를 유지한다.
- 두 OS 모두 로그 사용 선택을 환경설정 맨 아래에 배치한다. 기본 꺼짐과 문제 진단 시에만 켜라는 안내를 유지한다.

## 검사와 근거

Windows 로컬 격리 검사의 코어 **1,559개**, UI **639개**가 통과했다. 인증정보 보호(DPAPI)는 정상 사용자 보안 컨텍스트에서 검사했고, 실제 SafeSync 앱·계정·작업은 변경하지 않았다. 새 VSS 네이티브 보조 프로그램의 MSVC 빌드도 통과했다.

Windows GitHub Actions는 Windows Server 2022/2025 각각의 새 가상 NTFS 드라이브와 loopback SMB 공유에서 재시작·USN·네트워크·삭제 보호를 검사한다. VSS 검사는 이 시험 드라이브의 배타 잠금 파일을 실제 볼륨 사본에서 읽고 종료 뒤 사본 경로가 사라졌으며 원본이 그대로인지 확인한다. 최종 실행: [40494060956](https://github.com/limfrog/SafeSync/actions/runs/40494060956).

macOS 15 GitHub Actions는 로컬·메모리 Google Drive/Dropbox의 초기 백업, 변경 보류, 재시작한 검토 기록, 오래된 승인 거절, 승인 후 실행, 묶음 보관, 스트리밍 복원 검증, 손상 사본 거절, 원본 없는 현재 백업 검증, 양방향 대량 역삭제 보호와 작업 내보내기 정책 보존을 검사한다. 기존 통합 검사·XCTest·실제 앱 Store 경로 회귀 검사, arm64/x86_64 Universal 빌드·번들·임시 서명 검사도 수행한다. 최종 실행: [40494783704](https://github.com/limfrog/SafeSync/actions/runs/40494783704).

## 범위와 제한

이번 기능은 사용자의 실제 NAS·클라우드 파일을 변경하는 시험 없이 격리 검사했다. 메모리 서비스 검사는 실서비스 장애·할당량·모든 NAS/파일시스템의 호환성을 보증하지 않는다. VSS는 일반 Windows 10/11 데스크톱의 모든 애플리케이션 writer 조합을 시험한 것은 아니다. 코드 서명·Apple 공증·클라우드 공개 심사 완료를 뜻하지 않는다.

대량 변경은 메타데이터에 기반한 실행 단위 사전 보호다. 파일 수·시간·식별자를 모두 보존한 내용 변경이나 기준 미만으로 나뉜 변경을 탐지하는 랜섬웨어 방지 기능이 아니다. 새로 생성된 파일을 삭제하는 전체 시점 롤백도 아니다. 보관 중인 이전 파일만 복원하며 기본 100일 보관 정책은 유지한다.

이전 사본/기준에 체크섬이 없거나 폴더 전체 체크섬이 없으면 기준 없음으로 표시한다. 검증 기록은 같은 사용자 권한의 악의적 동시 변조를 막는 서명이 아니다. VSS는 저장되지 않은 메모리 내용이나 모든 데이터베이스의 정합성을 보증하지 않으며 전체 이미지 백업이 아니다.

Google Drive는 `drive.file` 앱 관리 폴더의 단방향 정책을 유지한다. 로컬·NAS·Dropbox 양방향은 유지한다. [사용법과 조건](../RECOVERY-GUIDE.md)을 참고한다. 패키지 해시는 `dist/SHA256SUMS.txt`와 별도 패키지 결과 문서에 기록한다.
