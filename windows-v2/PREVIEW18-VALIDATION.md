# Windows preview.18 — 빠른 클라우드 비교

2026-10-24. 일반 재시작 비교는 검증 성공 후 저장한 원본 크기·생성/수정 시각·파일 식별자 및 클라우드 전체 항목 정보가 일치하면 내용을 재독하지 않는다. 변경 이벤트, 미완료/실패, 수동 선택, 중복 경로, 정밀 전체 검사는 재사용에서 제외한다. 기존 스냅샷에 검증 정보가 없으면 첫 비교는 여전히 내용을 읽으며 성공 후 새 정보를 저장한다.

NAS 감시 공백의 파일 목록 확인은 유지한다. 크기·시각·식별자를 그대로 유지한 오프라인 내용 변경은 일반 비교에서 놓칠 수 있다. 작업 관리의 전체 검사는 모든 내용을 다시 검증한다. 전송 체크섬, 임시 교체, 루트/삭제 직전 검증, 복구 및 휴지통 보호는 유지한다. 클라우드 변경 목록을 갱신한 뒤의 정보만 재사용하며 원본 재검사 자체를 클라우드 전체 조회로 확장하지 않는다.

양방향 재시작 역시 원본 목록 재열거와 내용 정밀 검사를 분리한다. 명시적인 전체 검사, 변경 이벤트, 실패, 사용자 처리 선택은 기존 내용 재검증을 유지한다.

격리 Windows CI에서 기존 회귀, 재시작/SMB, 설치본 UI 및 추가 모의 Google Drive/Dropbox 검사를 실행한다. 사용자 PC 앱과 실제 NAS/클라우드 데이터는 실행 검사 대상으로 사용하지 않는다. 실제 NAS의 소요시간 단축률이나 무손실 오프라인 감시를 보장하지 않는다.
