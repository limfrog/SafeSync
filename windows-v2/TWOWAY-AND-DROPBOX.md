# 양방향 동기화 · Dropbox 외부 배포

1.0.0-preview.1 · 2026-10-19

## 작업 방향

새 작업/편집에서 `단방향 백업 →` 또는 `양방향 동기화 ↔`를 선택한다. 기존 설정에 방향이 없으면 단방향이다. 방향이나 연결 폴더를 바꾸면 새 작업 ID로 최초 비교를 시작한다. 작업 목록 내보내기/가져오기도 방향을 보존한다.

양방향 첫 실행은 양쪽 파일을 합친다. 같은 경로의 내용이 다르면 최신 시간만으로 덮어쓰지 않고 충돌로 남긴다. 이후 마지막으로 양쪽이 일치했던 성공 기록을 기준으로 판단한다.

| 이후 상태 | 동작 |
|---|---|
| 원본만 수정 | 원본 → 백업 |
| 백업만 수정 | 백업 → 원본 |
| 원본 삭제, 백업은 이전 내용 유지 | 백업을 백업 위치 휴지통으로 이동 |
| 백업 삭제, 원본은 이전 내용 유지 | 원본을 원본 위치 휴지통으로 이동 |
| 양쪽 모두 수정되어 내용이 다름 | 충돌, 양쪽 유지 |
| 한쪽 삭제와 다른 쪽 수정이 겹침 | 충돌, 수정 사본 유지 |
| 내용이 같음 | 전송 생략 |
| 한쪽 위치에 접근 불가 | 삭제로 간주하지 않고 중단 |

충돌 화면에서 원본→백업, 백업→원본(양방향만), 기존 백업 이름 변경 후 복사, 이번에는 변경 안 함을 선택한다. 충돌·잠김·실패는 마지막 성공 기준을 바꾸지 않고 다음 실행에 남긴다. 다른 파일은 계속 처리한다. 서비스 인증/통신 오류는 무의미한 반복 요청을 피하려고 남은 항목을 대기로 남긴다.

자동 실행은 변경 경로·USN·클라우드 커서·미처리 항목을 사용한다. 최초/수동 전체 비교/변경 기록 손실 때는 안전 재확인을 한다. 시간 경과만으로 전체 비교를 강제하지 않는다. 수동 전체 비교는 내용 체크섬도 재계산한다.

## 보호와 휴지통

- 로컬/NAS: 임시 사본, SHA-256 검증, 원자적 교체, 이전 버전 휴지통, 중단 복구.
- 클라우드 역방향: 다운로드 임시 사본의 서비스 체크섬과 다운로드 전후 원격 정보를 확인한 후 원본에 안전 반영.
- 교체 전 대상이 여전히 비교 때의 내용인지 확인. 읽는 원본은 쓰기/삭제를 허용하지 않는 핸들로 보호.
- 파일 삭제는 각 위치 `.safesync-trash`에 보관, 기본 100일 후 정리. 양방향 휴지통 창에는 `원본 휴지통` 버튼 제공.
- 빈 폴더 구조도 반영. 삭제할 폴더에 남은 항목이 있으면 강제 삭제하지 않음. 링크/연결 지점, 파일-폴더 충돌, 일반 파일이 아닌 클라우드 문서는 자동 교체하지 않음.
- 루트 식별 정보가 바뀌면 삭제를 중단. NAS가 생성 시간을 바꿔 반환할 수 있으므로 볼륨/파일 ID 우선 사용.

양방향은 삭제가 전파되므로 독립 백업의 대체가 아니다. 다른 앱/기기가 동시에 쓰는 상황에서 운영체제/서비스가 제공하지 않는 전역 트랜잭션을 보장하지 않는다. 별도 오프라인 백업도 권장한다. 내용이 같고 시간만 다른 파일은 불필요한 전송을 하지 않는다. ACL/소유권/확장 속성/Mac 전용 메타데이터의 완전 복제 기능은 아니다.

## Dropbox

등록 앱은 **SafeSync Personal**이며 공개 App Key `08al8ot9uye36k9`를 빌드 기본값으로 넣었다. 공개 클라이언트 식별자인 App Key는 비밀 키가 아니다. 사용자마다 개발자 앱을 만들 필요가 없다. App Secret/비밀번호/공유 토큰은 배포본에 넣지 않는다. 사용자는 본인 계정을 OAuth PKCE + 오프라인 연결로 승인하고 토큰은 해당 Windows 사용자 보호로 저장한다.

최소 권한은 `account_info.read`, `files.metadata.read`, `files.content.read`, `files.content.write`이며 공유/연락처/팀 관리/영구삭제 권한은 요청하지 않는다. 반환 주소는 `http://127.0.0.1:53682/`이다.

폴더 선택 때는 전체 Dropbox에서 기존 폴더를 탐색하거나 새 폴더를 만든다. 실행 저장소는 선택 경로/폴더 ID/계정에 묶는다. 경로 이탈, 인접 접두사 폴더, 루트 교체, 계정 불일치를 거부한다. 새 작업에서 Dropbox 최상위 전체를 바로 선택하는 것은 실수 방지를 위해 막는다.

**선택 폴더 제한은 SafeSync 내부의 실행 범위 제한이다. Full Dropbox 토큰 자체가 한 폴더 전용 권한으로 축소되는 것은 아니다.** Dropbox에서 SafeSync 휴지통 파일을 제거해도 서비스 자체 복구 정책이 별도로 적용될 수 있다.

## 배포와 검사

앱 생성, 최소 권한, 반환 주소, 외부 개발 사용자 연결, 소개/정책 링크, 64/256px 아이콘 설정 완료. 실제 Dropbox 계정에서 32개 검사가 통과했다. Production 승인은 별도이며 개발 사용자 허용과 다르다. Development 상태의 최대 500명 허용은 무제한 공개 승인이 아니다. 공개 심사에 사용할 다운로드와 홈페이지는 1.0.0-preview.1로 갱신한다.

실계정 검사는 명시적 옵션으로만 실행하고 매번 새 `SafeSync-validation-*` 폴더만 사용한다. 실제 인증 정보는 `artifacts/` 안 격리 설정에 암호화 저장되며 빌드/설치본/저장소 업로드에서 제외한다. 결과는 `RELEASE-VALIDATION.md`, `TEST-RESULTS.md`를 참조한다.
