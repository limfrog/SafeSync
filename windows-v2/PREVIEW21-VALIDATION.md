# Windows preview.21 — 반복되는 클라우드 중복 검사 수정

Google Drive가 같은 이름의 여러 물리 파일을 허용하는 경우에도 모든 사본의 크기와 체크섬이 원본과 같고, 검사 전후 사본 ID·메타데이터가 그대로라면 그 사본 묶음을 검증된 상태로 저장한다. 이후 변경 피드에 관련 경로가 없으면 매 분 같은 파일을 다시 해시하지 않는다.

사본·부모 폴더·원본 파일 중 하나라도 바뀌거나 사용자가 전체 검사를 실행하면 저장된 빠른 판단을 폐기하고 다시 비교한다. 내용이 다른 중복 사본은 기존처럼 충돌로 남기며 자동 덮어쓰기·삭제 권한을 얻지 않는다. 병렬 파일 검사 중에도 검증 기록 저장은 직렬화한다.

[GitHub Windows Server 2022/2025 검사](https://github.com/limfrog/SafeSync/actions/runs/40081237109)는 재시작·NAS·핵심 회귀와 설치 파일 생성·검증을 모두 통과했다.
