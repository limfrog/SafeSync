SafeSync 개인정보처리방침

시행일 2026-10-27 · 제한 권한 및 선택 진단 로그 안내

최신 전체 방침은 Horizon 공식 개인정보처리방침에서 확인할 수 있습니다.

SafeSync는 Windows와 macOS에서 사용자가 선택한 위치의 파일·메타데이터·작업 설정·OAuth 계정 정보를 백업·양방향 동기화·복구에 사용합니다. Dropbox 양방향에서는 클라우드 수정과 삭제도 컴퓨터에 반영됩니다. 인증 토큰은 Windows에서는 DPAPI로 보호해 로컬 저장하고 macOS에서는 Keychain에 저장합니다. 파일과 토큰을 운영 서버에 수집하지 않습니다. Google Drive와 Dropbox로의 전송에는 HTTPS를 사용합니다.

Google Drive는 drive.file 권한으로 앱이 만들거나 직접 허용한 파일만 사용하며 앱 관리 폴더의 단방향 백업을 제공합니다. 폴더 선택으로 다른 앱의 하위 파일 전체가 허용되지는 않습니다. Dropbox는 Full Dropbox 권한으로 탐색하고 실행은 선택 위치로 제한하며 토큰 자체가 한 폴더 전용으로 축소되지는 않습니다. 작업·계정 연결은 앱에서 중지·해제할 수 있고 서비스 계정에서 승인 철회도 가능합니다. 앱 제거는 기존 백업과 설정을 자동 삭제하지 않습니다. SafeSync 휴지통은 기본 100일 보관하며 서비스 자체 복구 정책은 별도입니다.

업데이트 자동 확인·자동 다운로드는 환경설정에서 각각 끌 수 있습니다. GitHub에 HTTPS로 접속하며 백업 파일·경로·계정·토큰·작업 기록은 보내지 않습니다. IP 주소 등 일반 연결 정보가 GitHub에 전달될 수 있고 GitHub 개인정보처리방침이 적용됩니다. 설치는 사용자 확인 없이 실행하지 않습니다.

SafeSync로 돌아가기

상세 로그는 기본으로 꺼져 있고 환경설정에서 선택합니다. 단계별 시간·전송량·오류 유형과 네트워크 진행 정보를 기기에만 순환 보관하며 실제 경로·내용·주소·인증정보는 기록하거나 자동 전송하지 않습니다. 상세 64MiB·요약 16MiB 한도와 기록 시작/순환 시 14일 정리를 적용합니다.

대량 변경 검토 목록·사본 체크섬·실행 정보는 기기 또는 지정 백업 위치에 저장합니다. 복원 검증은 별도 로컬 임시 파일을 읽고 정리하며, Windows VSS 선택 시 임시 볼륨 사본을 작업 뒤 정리합니다.
