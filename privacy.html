SafeSync 개인정보처리방침

SafeSync는 사용자가 선택한 파일을 사용자의 Google Drive에 백업하기 위한 개인용 Windows 애플리케이션입니다.

시행일: 2026년 10월 2일

게시 전 확인: 이 문서 아래의 연락처 이메일을 실제 운영자 이메일로 변경해야 합니다.

1. 적용 범위

본 개인정보처리방침은 SafeSync 애플리케이션과 SafeSync가 제공하는 Google Drive 백업 기능에 적용됩니다. SafeSync는 개인용으로 제공되며, 광고 또는 이용자 추적을 목적으로 개인정보를 처리하지 않습니다.

2. 처리하는 정보

SafeSync는 기능 제공을 위해 다음 정보를 처리할 수 있습니다.

  • Google OAuth 인증 토큰 및 Google Drive 연결 상태
  • 사용자가 직접 지정한 원본 폴더와 백업 위치
  • 백업 대상 파일의 이름, 경로, 크기, 만든 시간 및 수정 시간
  • 사용자가 백업하도록 지정한 파일의 내용
  • 백업 일정, 충돌 기록, 실행 결과 및 오류 기록

SafeSync는 사용자가 지정하지 않은 폴더를 임의로 검색하거나 백업하지 않습니다.

3. 정보 이용 목적

처리되는 정보는 다음 목적으로만 사용됩니다.

  • 사용자의 Google 계정 인증 및 Google Drive 연결
  • 파일 업로드, 갱신, 복원 및 백업 상태 확인
  • 파일 크기와 시간 정보 비교를 통한 변경 파일 판단
  • 예약 백업 및 파일시스템 변경 감지 기능 제공
  • 파일 충돌, 백업 실패 및 사용자 확인이 필요한 상황 안내
  • 백업 휴지통 및 보존기간 관리

4. Google 사용자 데이터의 이용

SafeSync는 사용자가 명시적으로 승인한 Google Drive 권한만 사용합니다. Google Drive에서 얻은 정보는 백업 파일을 만들고 관리하며 복원하는 기능에만 사용됩니다. 해당 정보는 광고, 신용평가, 이용자 프로파일링 또는 판매 목적으로 사용되지 않습니다.

SafeSync의 Google API 정보 이용은 제한적 이용 요건(Limited Use requirements)을 포함한 Google API Services User Data Policy를 준수합니다.

5. 정보의 저장과 전송

  • 애플리케이션 설정과 백업 기록은 사용자의 Windows 기기에 저장됩니다.
  • 백업 파일은 사용자가 선택한 Google Drive 계정으로 직접 전송됩니다.
  • Google OAuth 인증 정보는 Google Drive 연결 유지 목적으로 사용자 기기에 저장됩니다.
  • SafeSync 운영자는 별도의 중앙 서버를 통해 사용자의 파일 내용이나 인증 정보를 수집하지 않습니다.

인터넷 전송 과정에는 Google이 제공하는 암호화된 HTTPS 연결을 사용합니다.

6. 제3자 제공

SafeSync 운영자는 사용자의 개인정보나 파일을 판매하거나 제3자에게 제공하지 않습니다. 다만, 사용자가 Google Drive 백업 기능을 이용하면 Google은 서비스 제공자로서 관련 데이터를 처리합니다. Google의 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

7. 보유기간과 삭제

  • 로컬 설정과 실행 기록은 사용자가 앱 설정을 초기화하거나 관련 파일을 삭제할 때까지 보관됩니다.
  • Google Drive에 생성된 백업 파일은 사용자가 삭제하거나 SafeSync의 보존 정책에 따라 삭제될 때까지 보관됩니다.
  • 백업 과정에서 삭제 대상으로 처리된 파일은 SafeSync 휴지통에 최대 100일 동안 보관된 후 자동 삭제될 수 있습니다.
  • Google 연결을 해제하면 SafeSync는 더 이상 해당 Google Drive에 접근하지 않습니다.

사용자는 Google 계정의 서드 파티 앱 및 서비스 연결 페이지에서 언제든지 SafeSync의 접근 권한을 철회할 수 있습니다. 이미 Google Drive에 저장된 백업 파일은 사용자가 직접 삭제할 수 있습니다.

8. 정보 보호

SafeSync는 필요한 범위로 접근 권한을 제한하고, 인증 정보와 설정 파일에 대한 불필요한 노출을 방지하는 등 합리적인 보호 조치를 적용합니다. 다만 어떠한 저장 또는 전송 방식도 절대적인 안전을 보장할 수는 없으므로, 사용자는 Windows 계정과 Google 계정을 안전하게 관리해야 합니다.

9. 사용자의 선택과 권리

사용자는 언제든지 다음 작업을 할 수 있습니다.

  • 백업 대상 폴더와 Google Drive 백업 위치 변경
  • 자동 백업 및 예약 백업 중지
  • Google 계정 연결 해제 및 OAuth 접근 권한 철회
  • 로컬 백업 기록과 Google Drive 백업 파일 삭제

10. 아동의 개인정보

SafeSync는 만 14세 미만 아동을 대상으로 제공되는 서비스가 아니며, 운영자가 이를 인지한 상태에서 아동의 개인정보를 수집하지 않습니다.

11. 개인정보처리방침 변경

애플리케이션 기능이나 관련 법령이 변경되면 본 방침을 수정할 수 있습니다. 중요한 변경사항은 이 페이지 또는 애플리케이션 내 안내를 통해 고지하며, 문서 상단의 시행일을 갱신합니다.
