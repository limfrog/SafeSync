SafeSync 개인정보처리방침

시행일 2026-10-21 · 개발자 및 문의 정보 갱신

최신 전체 방침은 Horizon 공식 개인정보처리방침에서 확인할 수 있습니다.

SafeSync는 사용자가 선택한 위치의 파일·메타데이터·작업 설정·OAuth 계정 정보를 백업·양방향 동기화·복구에 사용합니다. 양방향에서는 클라우드 수정과 삭제도 PC에 반영됩니다. 인증 토큰은 Windows 사용자 보호 기능으로 로컬 저장하며 파일과 토큰을 운영 서버에 수집하지 않습니다. Google Drive와 Dropbox로의 전송에는 HTTPS를 사용합니다.

전체 Drive/Full Dropbox 권한으로 폴더를 탐색·선택·생성하며 실행 작업은 선택 위치로 제한합니다. OAuth 토큰 자체가 한 폴더 전용으로 축소되지는 않습니다. 작업·계정 연결은 앱에서 중지·해제할 수 있고 서비스 계정에서 승인 철회도 가능합니다. 앱 제거는 기존 백업과 설정을 자동 삭제하지 않습니다. SafeSync 휴지통은 기본 100일 보관하며 서비스 자체 복구 정책은 별도입니다.

업데이트 자동 확인·자동 다운로드는 환경설정에서 각각 끌 수 있습니다. GitHub에 HTTPS로 접속하며 백업 파일·경로·계정·토큰·작업 기록은 보내지 않습니다. IP 주소 등 일반 연결 정보가 GitHub에 전달될 수 있고 GitHub 개인정보처리방침이 적용됩니다. 설치는 사용자 확인 없이 실행하지 않습니다.
