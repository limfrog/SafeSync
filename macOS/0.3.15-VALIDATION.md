# macOS 0.3.15 (24) — 클라우드 연결 검증 수정

2026-10-24 · Horizon Entertainment · apps@horizonent.co.kr

연결 검증의 시험 원본이 SafeSync 자체 데이터 폴더 아래 만들어져 백업 제외 정책에 의해 파일 수가 0이 되던 문제를 수정한다. 시험 원본은 macOS 임시 폴더의 고유한 `SafeSync-connection-diagnostic-UUID` 아래 만들고 검증 종료 시 제거한다. 클라우드에는 기존처럼 새 `SafeSync-test-UUID` 폴더만 사용하며 기존 작업·사용자 파일은 변경하지 않는다.

클라우드 계정 창 하단에 고정된 진행·결과 영역을 추가해 환경설정을 닫지 않고 계정/루트 확인, 전송, 체크섬, 변경 없음, 교체, 충돌 보호, 휴지통과 복구 단계를 확인할 수 있다.

GitHub macOS 15의 통합·XCTest·실제 Store 경로 검사와 Apple Silicon/Intel Universal·번들·서명·ZIP 검사를 통과한 뒤 실행 번호와 해시를 이 문서에 추가한다. 실제 Dropbox/Google 계정 전송은 자동검사의 모의 저장소와 별도로 사용자가 연결 검증 버튼을 눌러 확인한다.
