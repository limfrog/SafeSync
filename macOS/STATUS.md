## 0.3.17 안정 중복 재검사 생략

- 동일 이름 원격 사본 전체가 원본과 같은 내용임을 확인하면 사본 집합과 원본 식별정보를 저장한다.

- 세부 범위와 최종 빌드 증거는 [0.3.16 검증 문서](0.3.16-VALIDATION.md)에 기록한다.

## 0.3.13 네트워크 오류·실행 중 예약·업데이트 진입

- 수정 전 [독립 재현 39725281365](https://github.com/limfrog/SafeSync/actions/runs/39725281365), 소스 `9d8c3a0`: 제품 코드를 변경하지 않은 상태에서 모의 Google Drive/Dropbox·단방향/양방향 네 경우 모두 일회 503 오류가 일반 오류로 남고 다음 엔진 실행에 복구됨을 확인했다. Store와 UI 소스에서는 메시지·오류 알림·문제 해결 목록에서 네트워크 오류를 구분하지 않고, 실행 중 비교 권한을 차단하는 것을 확인했다.
- 일시적 URL/POSIX 네트워크·408/429/일부 5xx 오류를 진단 목록 전용으로 분리했다. 동기화 끝에 한 번 재시도하고 지속 실패는 지연하며, 파일 감시 이벤트가 실패 횟수·대기를 초기화하던 조건도 고쳤다. 인증·권한·공간·체크섬 오류·실제 충돌과 사용자 취소를 자동 덮어쓰기 권한으로 해석하지 않는다. 기존 오류 JSON에는 선택적 필드를 추가하여 호환성을 유지한다.
- 실행 중 버튼은 파일별로 즉시 예약하고 실행 전 마지막 선택만 유지한다. 원래 동기화 전체 이후 비교한 파일·위치·계정/모드를 재검증하여 실행한다. 선택 취소·실행 중 변경 잠금·세션 한정·중단/작업 자체 실패/위치 변경 취소를 제공한다. 중단 후 대기한 작업도 새 수동 재비교를 허용한다. 기존 즉시 적용의 전체 사전 검증과 휴지통 보존은 유지한다.
- 두 OS 모두 환경설정의 업데이트 진입은 **업데이트 확인** 하나로 정리한다. 실제 다운로드·검증·사용자 교체 절차와 자동 확인/다운로드 설정은 유지한다.
- 최종 [macOS 15 실행 39728552265](https://github.com/limfrog/SafeSync/actions/runs/39728552265), 소스 `7e98b45f9087d4ca235fd7ee5187d293a5e1ef55`: 기존 통합 시나리오 100개와 추가 네트워크 정책·예약 보호 검사, XCTest **10개**, 실제 Store 경로 **24개 시나리오** 전부 통과. 24개는 두 제공자×두 모드에서 일회/지속 오류 8개와 예약 적용/취소/파일 변경/명시 중단 16개다. 지속 오류에서는 두 번의 실패 후 약 60초 대기를 확인했다.
- Store 검사는 앱 원본을 컴파일하고 프로세스 진입점만 교체하여 임시 데이터 및 모의 RemoteStorage로 실행했다. 실제 화면에서 마우스로 버튼을 누른 검사로 계산하지 않는다. 업데이트 진입은 소스의 단일 버튼 조건을 확인하고 앱 전체를 빌드했다. Universal x86_64/arm64, 버전·빌드·앱 ID·기존 Google 등록 리소스·ad-hoc 엄격 서명·ZIP 검사도 통과했다.
- 이번 과정의 첫 검사용 비공개 생성자 접근 오류는 공개 HTTP 오류 생성기로 수정했다. 초기 앱 검사에서 발견한 재시도 대기 초기화는 수정 후 최종 전체 실행으로 재검증했다. 실패한 중간 산출물은 게시하지 않는다.
- 앱 ID·Application Support 경로·Keychain·계정 리소스와 기존 백업을 유지한다. 양방향 전체 비교 증분화·백그라운드 서비스 설치 변경은 아니다. 실제 Mac UI 클릭·실계정 Google/Dropbox·NAS 장애·Intel 실행·장기 운전·Developer ID/Apple 공증은 별도다. 배포 크기·SHA-256과 Windows 결과는 [최종 배포 검사](../windows-v2/PREVIEW17-PACKAGE-RESULT.md)를 확인한다.

## 0.3.11 이전 이력 재비교와 로딩 상태

- 이전 문제 목록을 현재 파일로 재비교할 수 있다. 기존 최신 이력 제한을 우회해 무조건 쓰는 것이 아니라 현재 실행 세대와 작업 ID·원본·백업·서비스·계정·폴더·방향에 묶인 새 비교 권한을 얻는다.
- 새 실행·위치 변경 시 선택과 권한을 무효화하며 적용 단계에서도 다시 확인한다. 파일 비교 이후 사본이 바뀌면 덮어쓰지 않고 보존한다. 전체 선택 선행 검증과 이전 사본 휴지통 보존은 유지한다.
- 실행 중에는 기존 안전한 작업 종료 경로로 중단·대기한 뒤 재비교한다. macOS의 종료는 취소·복구 기록 보존 경로이며 Windows의 파일 경계 종료와 동일한 처리 시간을 보장하지 않는다.
- 비교 로딩 중 탭을 나가면 진행 상태를 초기화하고, 다시 나타나면 선택 정보를 재확인한다. 시작 로그의 ‘macOS 개발 버전’ 문구를 ‘SafeSync [버전] 시작’으로 바꿨다. 맥 버전에는 기존에도 C#/.NET·PowerShell 전환 문구가 없었다.

## 0.3.10 비교·삭제 보호 및 변경 감시 시작 검증

- 선택된 비교 파일은 크기·시각이 같아도 내용을 검증한다. 내용이 다른 파일을 동일 파일로 기록하지 않는다.
- 원본/로컬 백업 루트의 장치·inode·생성 식별자, 원격 선택 폴더 ID를 저장한다. 루트 교체·연결 중단·접근 실패를 원본 삭제로 해석하지 않는다.
- 디렉터리 핸들 기준으로 실제 ENOENT만 부재로 확인한다. 중간 경로가 링크/일반 파일로 바뀌거나 접근할 수 없으면 삭제하지 않는다. 클라우드 비동기 요청 뒤에도 이동 직전 원본과 폴더를 다시 확인한다.
- 구버전 기록을 보존하면서 최초 한 번 재검증한다. 원본을 재확인하지 못한 구버전 삭제 기록은 자동 삭제 권한이 없으며 파일과 기록을 보존한다.
- 7일 등 경과 시간만으로 전체 검사하던 조건을 제거한다. 최초 실행·명시적 전체 검사·이벤트 손실·감시 미완료·네트워크 위치의 보수적 전체 검사는 유지한다.
- FSEvents 시작 직후 빈 flush를 준비 완료로 취급하지 않는다. 구체적인 커서와 HistoryDone을 사용하고 초기 준비 전에는 전체 검사한다. 실제 macOS에서 초기 대체 경로·기록 재생 완료·실제 파일 이벤트 전달을 검증했다. flush가 아직 데몬에 도착하지 않은 모든 파일시스템 변경까지 즉시 보장한다는 의미는 아니다.

## 남은 실제 검증과 차이

- 실제 Google Drive/Dropbox의 양방향 전송과 신규 Dropbox 기본 앱 로그인은 아직 통과로 표시하지 않음. 클라우드 검사는 메모리 제공자와 모의 HTTP 어댑터 검사이며 실서비스 검증을 대신하지 않음.
- 네이티브 화면 도구가 환경설정 창을 여는 단계에서 다시 종료되어, 설정/새 계정 탭의 실제 표시·로그인과 설정 저장/취소는 이번 화면 검사에서 완료하지 못함. 메인·탭·비교·복구는 위와 같이 확인.
- NAS·외장 디스크 분리·잠자기·대용량 장시간 전송, Intel 실기기와 다른 macOS 버전은 별도 검증 필요.
- 양방향 엔진은 양쪽 전체 목록·체크섬을 보수적으로 재확인한다. Windows USN/메타데이터 일괄 조회 최적화와 동일한 성능이라고 보장하지 않음. macOS 파일 잠금은 advisory 방식.
- 실행 이력은 앱 종료 시 사라짐(Windows와 동일). 영속 백업 기록·문제·재시도·변경 대기열은 계속 저장함.
- Developer ID 서명·Apple 공증·자동 앱 교체는 별도. 업데이트 확인·검증 ZIP 다운로드는 제공하며 앱 교체는 사용자가 수행한다. 이번 빌드는 ad-hoc 서명.

## 0.2.3 우선 보완

- 사용 중/변경 중 파일을 일반 오류와 분리하고, 최초 대기·최근 시도·횟수·다음 시도와 즉시 재시도 버튼을 추가했습니다. 파일별 대기 기록을 저장하고 자동 재시도는 30초~5분으로 조절합니다. macOS advisory 공유 잠금과 변경 검사를 사용하며 Windows의 강제 쓰기 제한과 같다고 표시하지 않습니다.
- 수동 백업의 강제 전체 검사 조건을 제거했습니다. 메인 콜백 큐를 막지 않고 FSEvents를 flush한 뒤 변경 대기열의 체크포인트를 잡습니다. 기록 미완료·감시 실패·네트워크·7일 경과·명시적 전체 검사는 보수적으로 전체 검사합니다. 증분 실행에서 처리하지 않은 기존 충돌과 대기 기록도 보존합니다.
- Google Drive 5 MiB 이하 multipart 단일 요청과 최대 2개 임시 업로드를 추가했습니다. 폴더 생성과 검증/배치/이전 버전 보존은 순서대로 진행합니다. 경로별 임시 사본을 분리하고 실패·취소 시 이전 파일과 복구 기록을 보존합니다. 큰 파일의 재개 가능한 전송은 유지합니다.
- 완료 알림음 설정(기본 꺼짐)을 추가했습니다. 오류/대기 상태와 변경 없는 자동 확인에서는 완료음을 울리지 않습니다.
- 기존 32개와 보완 12개, 총 44개 검사가 통과했습니다. 보완 검사는 실제 파일 잠금/해제, 기존 사본 보존, 대기 기록/이전 JSON 호환, 증분 정책, Google 어댑터의 요청 구성(모의 HTTP), 2개 업로드 상한/동일 내용 파일 분리/실패 격리/취소 후 재시작/삭제된 경로의 오래된 문제 정리을 다룹니다.
- 검사 셸에서 FSEvents 서비스가 시작되지 않아 해당 시나리오는 감시 실패 시 전체 검사 전환을 검증했습니다. 실제 이벤트 전달과 수동 실행 직전 flush는 이 검사에서 통과한 것으로 표시하지 않습니다. 실제 Google/Dropbox API 검증과 NAS·잠자기 검증도 여전히 별도입니다.
- 남은 Windows 차이: 로컬 작업 병렬 실행, Google 메타데이터 일괄 요청, 휴지통 캐시, 기존 작업 경로 변경, 설치/업데이트 도구와 배포 공증.

### 0.2.3 네이티브 화면 확인

실행 앱의 설정에서 0.2.3과 완료 알림음 기본 꺼짐을 확인했습니다. `/private/tmp`의 전용 임시 작업으로 사용 중 대기 표·즉시 재시도 버튼·최초/최근/다음 시도·횟수를 확인했습니다. 잠긴 파일이 대기하는 동안 다른 파일의 복사를 확인했고, 편집기처럼 원본을 새 inode로 저장한 후 재시도하여 대기 0건과 복사 결과를 확인했습니다. 추가 파일의 수동 백업 후 파일 내용과 `lastFullScan`이 바뀌지 않은 것을 확인하여 네이티브 앱의 증분 경로도 확인했습니다. 검사 작업은 목록에서 제거했습니다. 완료 알림음의 실제 스피커 출력과 장시간 이벤트 경계/잠자기 검증은 별도입니다.

## 0.2.4 클라우드 폴더 생성

Google Drive/Dropbox 폴더 선택 창에 새 폴더와 새로고침 버튼을 추가했습니다. 현재 폴더를 부모로 생성하고 성공한 폴더 ID로 이동한 뒤 사용자가 현재 폴더 선택으로 확정합니다. 생성 중에는 중복 클릭·이동·시트 닫기를 막습니다. 이름 검증, 숨겨진 일반 파일을 포함한 중복 검사, 오류 표시와 새로고침을 지원합니다. 통신 오류 때는 생성 요청을 자동 반복하지 않습니다.

기존 44개에 폴더 생성 검사 4개를 추가하여 총 48개 자동 검사를 통과했습니다. 양 서비스의 부모/하위 폴더·한글 이름·중복, 잘못된 이름·파일 충돌, Google 어댑터의 폴더 MIME/부모 ID POST 요청(모의 HTTP), 생성 실패 전달을 확인했습니다. 실제 Google 계정의 폴더 생성 검증을 대신하지 않습니다.

네이티브 0.2.4 앱에서 기존 연결 계정의 실제 Google Drive 폴더 목록을 조회했고, 새 폴더 버튼·생성 위치·이름 입력 창·빈 이름/경로 구분자 차단·정상 이름의 만들기 활성화·취소를 확인했습니다. 실제 폴더 생성 요청은 보내지 않았습니다. 앱은 폴더 선택 창에 두었습니다.

## 0.2.5 환경설정과 About

Windows 1.9.13의 환경설정을 참고해 제목/설명, 보호 설정, 화면 모드, 하단 닫기/설정 저장 배치로 변경했습니다. 체크박스 알림음과 숫자 보관기간 입력을 사용하며 기존 시스템 화면 모드 선택도 유지합니다. 저장 전에는 설정을 변경하지 않고 보관기간을 검증한 뒤 자동 시작 등록과 환경설정을 적용합니다. 닫기 버튼은 편집 값을 버립니다.

앱 메뉴의 About SafeSync에 원본 아이콘, 버전/빌드, 제작자, 이메일과 GitHub 링크를 모았습니다. 버전은 번들 메타데이터에서 읽습니다. 환경설정의 버전/제작자/이메일 행은 제거했습니다. 독립 진행·휴지통·About 창에도 저장된 화면 모드를 적용합니다.

Universal 빌드·ad-hoc 서명 검증과 기존 48개 자동 검사를 통과했습니다. 새 앱의 메인 창 실행과 0.2.5 표시는 확인했습니다. 이후 화면 검사 도구의 네이티브 연결이 종료되어 환경설정/정보 창의 시각 검사와 실제 저장/취소 동작 확인은 완료하지 못했습니다. 도구 재연결 후 확인할 항목으로 남깁니다.
