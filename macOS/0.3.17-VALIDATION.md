# macOS 0.3.17 (26) — 반복되는 클라우드 중복 검사 수정

macOS에서도 Google Drive의 동일 이름 사본 전체가 원본과 같은 내용임을 확인한 뒤 사본 ID·크기·해시·수정 정보 묶음을 작업 기록에 저장한다. 앱 재시작·네트워크 원본 목록 확인·일반 원격 폴링 때 그 묶음과 원본 파일 식별정보가 그대로면 같은 파일을 작업 목록에 다시 넣지 않는다.

원본 또는 원격 사본 집합이 바뀌거나 사용자가 정밀 전체 검사를 요청하면 다시 내용을 검증한다. 내용이 다른 사본과 중복 폴더의 삭제 보호, 사본 보존형 이름 정리, 체크섬 검증은 유지한다.

[GitHub macOS 15 검사](https://github.com/limfrog/SafeSync/actions/runs/40080688535)는 통합 회귀·XCTest·실제 Store 경로와 Apple Silicon/Intel Universal 번들·서명·ZIP을 검증한다.
