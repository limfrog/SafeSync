# macOS 0.3.16 (25) — Google Drive 검증 및 자동 정리

Google Drive 연결 검증에서 루트 정보를 불필요하게 먼저 조회하던 단계를 제거하고 안정된 `root` 별칭을 직접 사용한다. 실패 메시지는 더 이상 `완료 수 불일치`로 끝나지 않고 복사·동일·휴지통 처리 수 또는 실제 파일 오류를 표시한다.

검증은 새 `SafeSync-test-<UUID>` 폴더에서만 실행한다. 전송·체크섬·증분·교체·휴지통·복구 검사를 마치거나 중간에 실패·취소되더라도 원격 시험 폴더 전체를 최대 3회 자동 삭제한다. 로컬 시험 자료도 OS 임시 폴더에서 제거한다.

GitHub macOS 15 [실행 40052236746](https://github.com/limfrog/SafeSync/actions/runs/40052236746)에서 통합 103개, XCTest 10개, 실제 앱 상태 경로 25개와 Apple Silicon/Intel Universal·번들·ad-hoc 엄격 서명·ZIP 검사를 통과했다. `SafeSync-macOS-0.3.16-universal.zip`은 4,265,704 bytes, SHA-256 `36c76302820413eef20cd29a182d2971d97db2ce33453e569e42ea03a49739e0`이다.
