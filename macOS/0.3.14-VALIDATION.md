# macOS 0.3.14 (23) — 빠른 클라우드 재시작 비교

Windows 1.0.0-preview.18의 검증 지문 재사용 정책을 macOS 단방향 백업과 양방향 동기화에 이식한다. 성공한 내용 검증 또는 검증된 전송 후에만 원본 크기·생성/수정 시각·파일시스템 식별자와 원격 항목 전체를 저장한다. 다음 실행에서 클라우드 변경 목록을 갱신한 뒤 두 지문이 모두 같은 항목은 파일 내용을 다시 읽지 않는다.

로컬 감시가 준비되지 않아 전체 파일 목록을 다시 조사하더라도 클라우드 목록 커서는 재사용한다. 사용자가 직접 요청한 전체 검사만 클라우드 목록과 내용을 처음부터 정밀 검증한다.

다음 항목은 빠른 비교에서 제외하고 기존 내용 검증을 유지한다.

- FSEvents 또는 저장된 변경 기록에 들어온 경로
- 미완료·실패·사용 중 대기가 남은 파일
- 이름 중복이나 사용자가 처리 방법을 지정한 파일
- 0.3.13 이하에서 생성해 검증 지문이 없는 기존 스냅샷의 첫 비교
- 작업 관리에서 사용자가 직접 실행한 전체 검사

크기·시각·파일 식별자를 모두 보존한 채 앱이 꺼져 있던 동안 내용만 변경하면 일반 빠른 비교에서 놓칠 수 있다. 의심되는 경우 전체 검사를 실행한다. 전송 체크섬, 안전한 임시 사본·교체, 삭제 직전 루트 재확인, 휴지통과 복구 기록은 유지한다.

검사는 GitHub macOS 15의 모의 Google Drive/Dropbox와 격리된 로컬 폴더로 수행한다. 실제 계정·NAS·Intel Mac 장기 운전·화면 클릭·Developer ID 공증은 별도 범위다.
