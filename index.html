로컬·네트워크·Google Drive·Dropbox의 단방향 백업과 양방향 동기화. PowerShell 없이 실행되는 C#/.NET Windows 데스크톱 앱입니다.

Windows 설치 EXEWindows 무설치 ZIP공식 홈페이지

1.0.0-preview.11 공개 프리뷰이며 안정판·코드 서명·클라우드 공개 심사 완료를 뜻하지 않습니다. 양방향은 한쪽의 삭제도 다른 쪽으로 전파합니다. 중요한 자료는 별도 백업하고 시험 폴더에서 먼저 확인하세요.

프리뷰 11 변경사항

크기와 수정 시간이 비슷해도 내용을 검증해 변경 파일 누락을 방지합니다. 원본 폴더 연결 중단·교체 시 삭제 반영을 차단하며, 중단된 클라우드 삭제도 원본 상태를 다시 확인합니다. 업데이트 후 최초 재검증은 평소보다 오래 걸릴 수 있습니다.

사용 안내

알림 영역 아이콘에서 메인창을 열고 새 작업의 원본·백업 위치와 방향을 선택하세요. Dropbox 공개 App Key는 포함되어 있지만 Production 승인 전 개발 사용자 한도가 적용됩니다. Google OAuth 설정과 검증은 별도입니다.
