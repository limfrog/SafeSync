1.0.0-preview.15 공개 프리뷰이며 안정판·코드 서명·클라우드 공개 심사 완료를 뜻하지 않습니다. 양방향은 한쪽의 삭제도 다른 쪽으로 전파합니다. 중요한 자료는 별도 백업하고 시험 폴더에서 먼저 확인하세요.

프리뷰 15 변경사항

NTFS 변경 기록의 읽기 접근과 폴더를 파일로 오인하던 반복 충돌을 수정했습니다. 변경 없는 두 번째 NTFS 재시작에서 전체 비교·파일 비교·재복사 0개를 확인했습니다. 처음에는 직전 자체 복사 기록을 다시 확인할 수 있으며, NAS 감시 공백이나 읽기 권한 제한 시 안전한 전체 비교는 유지합니다. 두 Windows 서버 환경에서 재현 95개와 핵심 1,030개 검사를 통과했습니다. 검사 결과와 범위

프리뷰 13 변경사항

새 버전 자동 확인·검증 다운로드와 환경설정의 수동 확인을 추가했습니다. 자동 확인과 다운로드는 개별 선택하며 설치는 사용자 확인 후 현재 파일을 마치고 진행합니다. 기존 버전에서는 이번 설치본을 한 번 직접 설치하세요. 업데이트 안내

프리뷰 11 변경사항

크기와 수정 시간이 비슷해도 내용을 검증해 변경 파일 누락을 방지합니다. 원본 폴더 연결 중단·교체 시 삭제 반영을 차단하며, 중단된 클라우드 삭제도 원본 상태를 다시 확인합니다. 업데이트 후 최초 재검증은 평소보다 오래 걸릴 수 있습니다.
