중요한 파일을
필요한 곳에 안전하게

SafeSync는 지정한 폴더의 변경을 감지하거나 정해진 시간에 백업을 실행하고, 로컬·네트워크 드라이브와 Google Drive에 파일을 보관하도록 설계된 개인용 애플리케이션입니다.

기능 살펴보기 개인정보처리방침

백업은 자동으로, 판단은 투명하게

백업이 필요한 순간을 감지하고 파일 상태를 비교해 필요한 작업만 수행합니다.

01

자동 실행

파일시스템 변경 감지 또는 사용자가 정한 일정에 따라 백업 작업을 자동으로 실행합니다.

02

파일 비교

만든 시간, 수정 시간과 크기를 비교해 최신 파일만 복사하고 같은 파일은 건너뜁니다.

03

충돌 알림

같은 파일로 보이지만 크기가 다르면 사용자에게 알리고, 다른 파일의 백업은 계속합니다.

04

다양한 저장 위치

로컬 드라이브, 네트워크 드라이브 또는 사용자가 연결한 Google Drive를 선택할 수 있습니다.

05

백업 휴지통

삭제되는 백업 파일을 별도 휴지통에 보관하고 최대 100일 후 정리하도록 설계했습니다.

06

개인 중심 설계

사용자가 지정한 위치만 처리하며, 광고나 행동 추적을 목적으로 파일 정보를 사용하지 않습니다.

Google Drive 권한을 요청하는 이유

SafeSync는 사용자가 Google Drive 백업을 선택한 경우에만 Google 계정 연결을 요청합니다. 승인된 권한은 백업 파일을 만들고, 갱신하고, 복원하거나 정리하는 목적으로만 사용됩니다.

  • 사용자가 선택한 Google 계정에 백업 파일 업로드
  • SafeSync가 만든 백업 파일과 폴더의 상태 확인 및 갱신
  • 사용자가 요청한 복원·삭제·휴지통 보존 작업 수행
  • 광고, 판매 또는 사용자 프로파일링 목적으로 사용하지 않음

파일과 인증 정보는 사용자가 통제합니다

SafeSync는 별도의 중앙 서버를 통해 사용자의 파일 내용이나 Google 인증 정보를 수집하지 않습니다. 설정과 실행 기록은 사용자 PC에 저장되고, 백업 파일은 사용자가 선택한 저장 위치로 직접 전송됩니다. Google 계정 접근 권한은 언제든지 철회할 수 있습니다.
