원하는 위치에 파일을 자동으로 백업하는 데스크톱 앱입니다. 로컬·외장·NAS·Dropbox는 단방향 백업과 양방향 동기화, Google Drive API는 앱 관리 폴더의 단방향 백업을 제공합니다.

Windows 설치 EXEWindows 무설치 ZIPmacOS Universal ZIP공식 홈페이지

공개 프리뷰이며 정식 안정판·코드 서명/공증·클라우드 공개 심사 완료를 뜻하지 않습니다. 양방향은 한쪽의 삭제도 반대쪽에 반영합니다. 중요한 자료는 별도로 백업하세요.

변경 기록으로 더 빠르게

Windows의 초기 Google Drive 목록은 폴더 ID·상위 관계와 변경 커서를 저장하고 계층 조회를 묶어서 처리합니다. 두 OS 모두 검증된 파일 정보를 재사용하며, 실제 업로드의 체크섬과 안전 교체는 유지합니다.

필요할 때만 상세 진단

환경설정 → 문제 진단에서 상세 로그를 켜고 끌 수 있습니다. 기본으로 꺼져 있고 문제가 있어 검증할 때만 켜세요. 초기 준비·파일 전송·연결 단계와 정체를 기기에 기록하며 인증정보·실제 파일 경로·파일 내용은 기록하지 않습니다.

Google Drive 제한 권한

전체 Drive 권한 대신 drive.file을 요청합니다. 앱이 만들거나 직접 허용된 파일만 볼 수 있어 Google API 양방향은 제공하지 않습니다. 이전 전체 Drive 권한 계정은 다시 연결하고 새 앱 관리 폴더의 작업을 만드세요. 기존 백업은 보존되며 새 위치로 처음 전송하는 시간과 공간이 필요합니다. 프리뷰 22~25에서 이전한 계정·작업은 계속 사용합니다.
